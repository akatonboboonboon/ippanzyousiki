# 常識のものさし

正解数から知識の習熟度を振り返り、ジャンル別の得意・苦手をレーダーチャートで確認できる、日本語の一般常識クイズアプリです。React・TypeScript・Viteで構成した、バックエンド不要のWebアプリです。

## できること

- **2,889問・12ジャンル・3段階**：暮らし、健康、お金、買い物、仕事、慣習、交通、防災、ネット、社会、ことば、科学と世界。画像問題も収録しています。
- **知識診断**：知識問題2,669問から60問。各ジャンル5問、初級2・中級2・上級1の配分です。お金・買い物の計算図は除き、10ジャンルから画像を1問ずつ出します。正解と解説は終了後に表示します。
- **自由練習**：「知識」「計算・読み取り」「すべての問題」を選択できます。計算・読み取りは220問。割引、単価、割り勘、時刻表などを診断とは別に練習できます。難易度・ジャンル・問題数（12・24・48・96・全問）でも絞り込めます。
- **正答率と正解数**：「85%」「60問中51問正解」のように表示し、100点換算やS〜Dランクは使いません。ジャンル別の正答率をレーダーチャートで表示し、間違えた問題を復習できます。
- **未出題を優先**：未出題が十分な場合は、直近で間違えた問題を最大2割まで混ぜます。不足する場合は以前に出た問題で補います。実際に表示した問題だけを記録します。
- **履歴・中断から再開**：このブラウザーに記録します。過去の標準診断1〜11は開始時の問題・選択肢・正答で復元できます。知識診断は新しい出題範囲のため、旧標準診断との前回比較は行いません。
- **問題ライブラリ**：検索、ジャンル・題材・難易度・画像の有無・問題の種類による絞り込みに対応。正解・解説と出典を確認できます。
- **ダークモード**：画面上部の「表示」で端末に合わせる・ライト・ダークを選べます。初期状態は端末の設定に従い、変更した設定はこのブラウザーに保存します。

診断で表示するのは、この問題集の知識問題への正答率です。一般常識全体や推論能力を測る標準化された検査ではありません。問題の追加履歴は[調査記録](docs/research/overview.md)、今回の改訂は[利用者の指摘への対応](docs/research/question-review.md)に記載しています。

## 開発・確認

Node.js 24とnpmを使用します。リポジトリのルートで実行してください。

```sh
npm install
npm run dev
```

ターミナルに表示されるローカルURLを開きます。通常は `http://127.0.0.1:5173` です。

```sh
# TypeScriptの型検査と本番ビルド
npm run build

# 問題データ・出題・採点・保存データの単体テスト
npm test

# Chromiumを準備し、画面操作のテスト
npx playwright install chromium
npx playwright test

# 本番ビルドをローカルで確認
npm run preview
```

Playwrightはテスト用サーバーを自動起動します。Linuxでブラウザーのシステム依存関係も導入する場合は、`npx playwright install --with-deps chromium` を使用します。

GitHub ActionsのCIはpushとpull requestで、Ubuntu・Node.js 24上の `npm ci`、ビルド、単体テスト、Chromiumの画面操作テストを実行します。失敗時は生成されたテスト結果・トレースを成果物として保存します。

## 結果の読み方

正答率は `Math.round(正解数 / 出題数 * 100)` です。例えば51問正解／60問出題なら85%と表示します。ジャンル別もその回の正答率を四捨五入します。前回80%・今回85%の差は「+5ポイント」です。

新規の知識診断は `mode: diagnostic`、`diagnosticVersion: standard-v12`、`questionScope: knowledge` を保存します。各ジャンル5問、初級24・中級24・上級12、画像は中級10問です。対象メタデータは `src/data/diagnostic-reviewed.json` に固定します。旧標準診断1〜11は当時の出題対象・配分・抽選を保持し、履歴・中断データを当時の問題で復元します。

比較は診断版が同じ結果に限ります。ホームと履歴の集計欄には新しい知識診断の結果を表示し、旧標準診断・自由練習・復習を混ぜません。過去の標準診断は個別の結果から同じ版同士で比較できます。自由練習の `questionScope` は `knowledge`・`reasoning`・`all`。この項目がない旧データは、従来どおり混合出題として復元します。

出題されなかったジャンルは `null` として保持し、「未測定」と表示します。0%とは区別します。難易度は編集上の目安です。出題数が少ないジャンルは結果が変わりやすく、この診断は一般常識全体・推論力・人格を測る検査ではありません。

## 記録とプライバシー

途中経過・最新50回の結果・問題ごとの出題済み情報と直近の正誤は、このアプリを開いたブラウザーの `localStorage`（キー：`monosashi-v1`）に保存します。アカウント登録は不要で、回答や履歴をアプリからサーバーへ送る処理はありません。

記録は同じ端末・ブラウザー・オリジンでのみ利用でき、端末間では同期しません。ブラウザーのサイトデータ削除や保存制限で失われる場合があります。保存できないときは画面に通知します。学習履歴画面から結果・出題済み情報・復習リストをまとめて削除できます。中断中のクイズは残り、再開して表示した問題から新しく記録します。

「完了した回数」と累計正答率は、**保存されている最新50回のうち、現在の問題だけで解いた結果**を基準に算出します。累計正答率には同じ問題への再回答も含み、古い結果が保存対象から外れると変わります。

出題済みの問題と直近の正誤は、結果履歴とは別の `learning` に保存します。クイズで実際に表示した時点で既出、回答を確定した時点で正誤を記録するため、未完了のクイズも反映されます。復習リストは現行IDの直近回答が誤答の問題です。復習で正解すると解除します。問題ライブラリ・結果画面の閲覧は出題済み記録に含めません。

旧形式の保存データは、有効な履歴と中断クイズの表示済み部分から移行します。すでに保存範囲から消えた過去の出題は復元できません。改訂前IDの学習状態を変更後の別IDへ移し替えず、同じ旧記録に含まれる現行IDの回答は個別に取り込みます。明示的に削除した空の記録を、中断クイズから自動で復活させません。

改訂前の問題を含む結果は「改訂前」と表示して残し、当時の問題・選択肢・正答で表示します。旧問題は新規出題、ライブラリ、復習から外します。選択肢改訂前に始めた12ジャンル版の中断データは、自由練習・復習・標準診断とも開始時の問題・選択肢で再開できます。標準診断1〜11は同じ版の過去結果との比較も維持します。最初の8ジャンル版を含む中断データは従来どおり終了し、画面に通知します。

## 静的ホスティング

`npm run build` で生成される `dist/` を静的ホスティングへ配置できます。Viteの `base` は `./` なので、サブディレクトリへの配置にも対応しています。開発サーバーやNode.jsを公開先で常駐させる必要はありません。CIには公開・デプロイ処理を含めていません。

Renderでは **Static Site** を選択します。ブランチは `codex/build-quiz-app`、Root Directoryは空欄、Build Commandは `npm ci --include=dev && npm run build`、Publish Directoryは `dist`、環境変数は `NODE_VERSION=24`。Start Commandは不要です。Renderが発行した公開URLは外部からアクセスできます。GitHubへのpush後に反映するには、自動デプロイを有効にするか手動デプロイを実行してください。
