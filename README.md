# 常識のものさし

正解数から知識の習熟度を振り返り、ジャンル別の得意・苦手をレーダーチャートで確認できる、日本語の一般常識クイズアプリです。React・TypeScript・Viteで構成した、バックエンド不要のWebアプリです。

## できること

- **2,004問・12ジャンル・3段階**：家事・暮らし、食と健康、お金・家計、買い物・契約、仕事・連絡、マナー・慣習、交通・公共、防災・安全、ネット・情報、社会・手続き、ことば・教養、身近な科学・世界。従来の1,284問に各ジャンル60問、合計720問を追加しました。家事202問、食と健康・買い物各172問、その他は各162問です。全体の難易度は初級792・中級756・上級456問です。
- **生活の知識へ範囲を拡充**：複数の一般常識クイズ集を比較し、公的機関・実務資料から題材を調査しました。教科中心だった旧版から分類を作り直し、上級も日常知識を状況へ当てはめる問題を中心にしています。[調査記録](docs/research/overview.md)と[出題方針](docs/question-policy.md)を公開しています。
- **標準診断**：60問を固定配分で出題。各ジャンルは初級の文章2問・中級の文章1問・中級の画像1問・上級の文章1問です。「標準診断 2」は追加した問題も出題します。正誤と解説は終了後に表示し、同じ版の前回結果と比較できます。以前の「標準診断 1」の履歴と中断データも引き続き利用できます。
- **画像問題**：12ジャンル各2問のオリジナルSVGを収録。洗濯表示、道路標識、図表、地図などを見て答えます。全画像に説明文があり、画像の読込失敗時にも表示します。
- **生活知識**：裁縫、靴の手入れ、衣替え・防虫、ペットとの暮らしなど60問を追加しました。[追加調査](docs/research/life-expansion.md)と[画像の出典](docs/research/visual-questions.md)を参照できます。
- **自由練習の条件を選択**：難易度は3段階またはミックス、ジャンルは複数選択。問題数は12・24・48・96問または全問から選べます。条件に合う問題が少ない場合は、その件数が上限です。「全問」も選択中の条件に合う問題が対象です。
- **偏りを抑えた出題**：選択ジャンルから順番に抽出し、ミックスでは難易度も分散します。同じチャレンジ内で問題を重複させず、問題と4択の順番をランダム化します。
- **回答と学習**：自由練習では正誤・正解・解説をその場で確認でき、出典がある問題は参照先を開けます。途中経過からの再開にも対応しています。
- **結果と復習**：正解数、100点換算のスコア、ランク、ジャンル別レーダーチャートを表示。最新50回の履歴を保存し、間違えた問題を再出題できます。
- **問題ライブラリ**：題材・問題・答え・解説の検索と、ジャンル・題材・難易度・出題形式（画像／文章）の絞り込みができます。スマートフォンでも利用できます。

## 開発・確認

Node.js 24とnpmを使用します。リポジトリのルートで実行してください。

```sh
npm install
npm run dev
```

ターミナルに表示されるローカルURLを開きます。通常は `http://127.0.0.1:5173` です。

```sh
# TypeScriptの型検査と本番ビルド
npm run build

# 問題データ・出題・採点・保存データの単体テスト
npm test

# Chromiumを準備し、画面操作のテスト
npx playwright install chromium
npx playwright test

# 本番ビルドをローカルで確認
npm run preview
```

Playwrightはテスト用サーバーを自動起動します。Linuxでブラウザーのシステム依存関係も導入する場合は、`npx playwright install --with-deps chromium` を使用します。

GitHub ActionsのCIはpushとpull requestで、Ubuntu・Node.js 24上の `npm ci`、ビルド、単体テスト、Chromiumの画面操作テストを実行します。失敗時は生成されたテスト結果・トレースを成果物として保存します。

## 構成

| 場所                       | 役割                                               |
| -------------------------- | -------------------------------------------------- |
| `src/App.tsx`              | 出題設定、回答、結果、履歴、復習、ライブラリの画面 |
| `src/Radar.tsx`            | SVGのレーダーチャート                              |
| `src/styles.css`           | レイアウト、配色、レスポンシブ表示                 |
| `src/data/`                | ジャンル・難易度・型定義、問題集、その集約         |
| `src/lib/quiz.ts`          | 抽出・シャッフル・採点・ランク・保存データの検証   |
| `tests/quiz.test.ts`       | データ整合性とクイズロジックの単体テスト           |
| `tests/browser/`           | Playwrightによる画面操作テスト                     |
| `public/`                  | ファビコンなどの静的ファイル                       |
| `.github/workflows/ci.yml` | ビルドとテストの自動実行                           |

現行問題は `src/data/practical-*.ts`、`src/data/visual-questions.ts`、`src/data/life-expansion.ts`、`src/data/expansion-*.ts`、公開済み旧版の600問は `src/data/archive-v1.json` にあります。問題を追加・修正する際は、`Question` 型に従い、重複しないID、`topic`、4個の異なる選択肢、0始まりの正答位置、解説を指定してください。制度・規則・健康・安全などは一次資料を確認し、`source` を付けます。基本問題のIDは `v2-ジャンル-難易度-連番`、画像は `v2-ジャンル-visual-連番`、最初の生活追加は `v2-ジャンル-extra-連番`、今回の720問は `v2-ジャンル-expanded-難易度-連番` で、旧IDを再利用しません。画像は `Question.image` の `src`（`public` からの相対パス）、`alt`（図の情報）、任意の `caption` を設定します。答えをそのまま画像の説明に書かず、図と同等の情報を文章でも提供します。今後の改訂でも既存IDの内容を変えず、アーカイブと現行IDの区別・保存データ検証を合わせて更新してください。

## スコアの読み方

スコアは `Math.round(正解数 / 出題数 * 100)` です。ジャンル別の値も、その回に出題された各ジャンルの正答率を四捨五入しています。自由練習は条件ごとの練習スコアです。標準診断の比較には含めません。問題数・ジャンル・難易度が異なる結果は、同じ条件の成績として比較できません。

新規の標準診断は `mode: diagnostic` と `diagnosticVersion: standard-v2` を保存します。標準診断2の母集団は2,004問、以前の標準診断1は従来の1,284問に固定しています。それぞれのID範囲を明示し、将来の追加問題が自動で混入しない設計です。どちらの版も、設定・問題内訳・画像数を復元時に検証します。出題配分は初級24・中級24・上級12、画像は中級12問。同じ版の保存済み結果だけを比較し、ホームと履歴の集計欄には最新の標準診断2のスコアを表示します。標準診断1の個別結果も閲覧・比較でき、中断中ならそのまま完了できます。配分が同じでも、ランダムな出題・学習効果による変動があります。

出題されなかったジャンルは `null` として保持し、「未測定」と表示します。0点とは区別します。ランクや難易度は学習用に編集した目安で、標準化された能力検査や、人格・社会性の評価ではありません。問題数が少ない場合は、出題内容によって結果が変わりやすくなります。

## 記録とプライバシー

途中経過と最新50回の結果は、このアプリを開いたブラウザーの `localStorage`（キー：`monosashi-v1`）に保存します。アカウント登録は不要で、回答や履歴をアプリからサーバーへ送る処理はありません。

記録は同じ端末・ブラウザー・オリジンでのみ利用でき、端末間では同期しません。ブラウザーのサイトデータ削除や保存制限で失われる場合があります。保存できないときは画面に通知します。学習履歴画面から結果と復習リストを削除でき、中断中のクイズは残ります。

累計正答率・出会った問題数・復習対象は、**保存されている最新50回のうち、現行問題だけで受けたチャレンジ**を基準に算出します。累計正答率には同じ問題への再回答も含み、復習リストは対象記録内の各問題への最新の回答が誤答だったものです。古い記録が保存対象から外れると、これらの集計も変わります。

改訂前の問題を含む結果は「改訂前」と表示して残し、当時の問題・選択肢・正答で表示します。旧問題は新規出題、ライブラリ、復習から外します。改訂前の問題を含む中断データは終了し、画面にその旨を通知します。

## 静的ホスティング

`npm run build` で生成される `dist/` を静的ホスティングへ配置できます。Viteの `base` は `./` なので、サブディレクトリへの配置にも対応しています。開発サーバーやNode.jsを公開先で常駐させる必要はありません。CIには公開・デプロイ処理を含めていません。

Renderでは **Static Site** を選択します。ブランチは `codex/build-quiz-app`、Root Directoryは空欄、Build Commandは `npm ci --include=dev && npm run build`、Publish Directoryは `dist`、環境変数は `NODE_VERSION=24`。Start Commandは不要です。Renderが発行した公開URLは外部からアクセスできます。GitHubへのpush後に反映するには、自動デプロイを有効にするか手動デプロイを実行してください。
