# 常識のものさし

正解数から知識の習熟度を振り返り、ジャンル別の得意・苦手をレーダーチャートで確認できる、日本語の一般常識クイズアプリです。React・TypeScript・Viteで構成した、バックエンド不要のWebアプリです。

## できること

- **2,597問・12ジャンル・3段階**：家事・暮らし、食と健康、お金・家計、買い物・契約、仕事・連絡、マナー・慣習、交通・公共、防災・安全、ネット・情報、社会・手続き、ことば・教養、身近な科学・世界。全体の難易度は初級1,010・中級1,022・上級565問です。ジャンル別の件数は[調査記録](docs/research/overview.md)に掲載しています。
- **条件の転記で解ける99問を再改訂**：全2,597問を再点検し、休館日の架空ルールや在庫・連絡内容をそのまま選ぶ問題を差し替えました。設問を読んだ後に必要な知識を確認し、用途・仕組み・用語を場面へ当てはめる内容にしています。価格比較など計算を目的とした問題は維持します。改訂前の履歴・中断クイズは当時の内容で復元できます。
- **日用小物・文具・遊び・園芸・図書館・撮影・宿泊に105問追加**：各15問（初級6・中級6・上級3問）で、30問は画像付きです。形や用途、場面に応じた使い分けを扱い、全問に解説と一次資料の出典を付けています。
- **100問の問題文を修正**：既存2,492問を確認し、使い方や意味を設問で説明してから同じ内容を選ばせる問題を改訂しました。似た用語・操作・目的を比較し、知識を使って判断する形にしています。改訂前の記録は当時の問題と選択肢で残します。
- **身近な8分野に120問追加**：路面表示、施設の案内マーク、間取り図、親族の呼び方、衣類・寝具、家電の機能、立替・割り勘、店の在庫と受け取りを各15問。うち48問は画像付きです。図の位置関係や実用的な表示を読み、必要な条件を当てはめて答えます。精算問題は負担の約束と送金の経路を明記しています。
- **身近な5分野・お得比較・標識に133問追加**：道具の仕組み、食品包装、光熱費の明細、ニュースの数字、外食の言葉を各15問、「どちらがお得？」を40問、道路標識を画像で見分ける問題を18問追加しました。価格比較では送料・ポイント・必要量・有効期限などの条件を明記し、全問に解説と出典を付けています。
- **1,160問の選択肢を改訂**：全2,239問を確認し、断定的な誤答や題材から外れた候補を、身近な取り違えを問う選択肢へ見直しました。正解だけが長い・慎重な文にならないよう、設問の条件も調整しています。問題数と難易度別の配分は維持しています。
- **買う・使う・手放す場面に115問追加**：住まい探しの費用、食品表示の読み分け、家電の処分、自転車の手入れ、身近なものの知識を各20問、乾電池の使い方を15問追加しました。「身近なものの知識」はお茶だけに限定せず、飲み物・食品・素材・道具などに広げています。各20問の分野は初級8・中級8・上級4問、乾電池は初級6・中級6・上級3問で、全問に解説と出典を付けています。
- **日常の6分野に120問追加**：落とし物、荷物の発送、料理の基本、車の日常点検、紫外線と外出、住まいのトラブルに各20問（初級8・中級8・上級4問）を追加しました。すべて文章問題で、解説と出典を付けています。
- **生活の知識へ範囲を拡充**：複数の一般常識クイズ集を比較し、公的機関・実務資料から題材を調査しました。教科中心だった旧版から分類を作り直し、上級も日常知識を状況へ当てはめる問題を中心にしています。[調査記録](docs/research/overview.md)と[出題方針](docs/question-policy.md)を公開しています。
- **標準診断**：60問を固定配分で出題。各ジャンルは初級の文章2問・中級の文章1問・中級の画像1問・上級の文章1問です。「標準診断 10」は改訂後の2,597問を対象に、未出題を優先します。正誤と解説は終了後に表示し、同じ版の前回結果と比較できます。以前の「標準診断 1〜9」の履歴と中断データも引き続き利用できます。
- **画像問題120問**：路面表示や施設マークなどの90問に、日用小物6・文具3・遊び6・園芸3・図書館3・撮影6・宿泊3を追加。全画像に説明文があり、画像の読込失敗時にも表示します。道路や施設の記号は[国土交通省・警察などの一次資料](docs/research/expansion-street-symbols.md)と図柄・意味を照合しています。
- **生活知識**：裁縫、靴の手入れ、衣替え・防虫、ペットとの暮らしなど60問を追加しました。[追加調査](docs/research/life-expansion.md)と[画像の出典](docs/research/visual-questions.md)を参照できます。
- **自由練習の条件を選択**：難易度は3段階またはミックス、ジャンルは複数選択。問題数は12・24・48・96問または全問から選べます。条件に合う問題が少ない場合は、その件数が上限です。「全問」も選択中の条件に合う問題が対象です。
- **未出題を優先**：自由練習と標準診断7〜10では、条件に合う未出題を優先し、直近の回答が誤答の問題を最大2割まで混ぜます。未出題が配分に足りない場合は、誤答、しばらく出ていない問題の順で不足を補います。途中クイズの未表示問題は既出にせず、出題済みの情報は履歴50回を超えて保持します。
- **偏りを抑えた出題**：選択ジャンルから順番に抽出し、ミックスでは難易度も分散します。同じチャレンジ内で問題を重複させず、問題と4択の順番をランダム化します。
- **回答と学習**：自由練習では正誤・正解・解説をその場で確認でき、出典がある問題は参照先を開けます。途中経過からの再開にも対応しています。
- **結果と復習**：正解数、100点換算のスコア、ランク、ジャンル別レーダーチャートを表示。最新50回の履歴を保存し、間違えた問題を再出題できます。
- **問題ライブラリ**：題材・問題・答え・解説の検索と、ジャンル・題材・難易度・出題形式（画像／文章）の絞り込みができます。スマートフォンでも利用できます。

## 開発・確認

Node.js 24とnpmを使用します。リポジトリのルートで実行してください。

```sh
npm install
npm run dev
```

ターミナルに表示されるローカルURLを開きます。通常は `http://127.0.0.1:5173` です。

```sh
# TypeScriptの型検査と本番ビルド
npm run build

# 問題データ・出題・採点・保存データの単体テスト
npm test

# Chromiumを準備し、画面操作のテスト
npx playwright install chromium
npx playwright test

# 本番ビルドをローカルで確認
npm run preview
```

Playwrightはテスト用サーバーを自動起動します。Linuxでブラウザーのシステム依存関係も導入する場合は、`npx playwright install --with-deps chromium` を使用します。

GitHub ActionsのCIはpushとpull requestで、Ubuntu・Node.js 24上の `npm ci`、ビルド、単体テスト、Chromiumの画面操作テストを実行します。失敗時は生成されたテスト結果・トレースを成果物として保存します。

## スコアの読み方

スコアは `Math.round(正解数 / 出題数 * 100)` です。ジャンル別の値も、その回に出題された各ジャンルの正答率を四捨五入しています。自由練習は条件ごとの練習スコアです。標準診断の比較には含めません。問題数・ジャンル・難易度が異なる結果は、同じ条件の成績として比較できません。

新規の標準診断は `mode: diagnostic` と `diagnosticVersion: standard-v10` を保存します。出題対象は標準診断1が1,284問、標準診断2が2,004問、標準診断3が2,124問、標準診断4が改訂前の2,239問、標準診断5が選択肢改訂後の2,239問、標準診断6・7が2,372問、標準診断8が問題文改訂前の2,492問、標準診断9が最初の問題文改訂後の2,597問、標準診断10が知識不要の条件読解を見直した2,597問です。標準診断7〜10は、ジャンル・難易度・画像の配分を維持して未出題を優先します。7は6から選び方を、8〜10は対象問題を変えたため別版として比較し、以前の1〜9の出題範囲と抽選方法は変更しません。それぞれのID範囲を固定し、将来の追加問題が自動で混入しない設計です。すべての版で設定・問題内訳・画像数を復元時に検証します。出題配分は初級24・中級24・上級12、画像は中級12問。同じ版の保存済み結果だけを比較し、ホームと履歴の集計欄には最新の標準診断10のスコアを表示します。標準診断1〜9の個別結果も閲覧・比較でき、中断中ならそのまま完了できます。配分が同じでも、ランダムな出題・学習効果による変動があります。

出題されなかったジャンルは `null` として保持し、「未測定」と表示します。0点とは区別します。ランクや難易度は学習用に編集した目安で、標準化された能力検査や、人格・社会性の評価ではありません。問題数が少ない場合は、出題内容によって結果が変わりやすくなります。

## 記録とプライバシー

途中経過・最新50回の結果・問題ごとの出題済み情報と直近の正誤は、このアプリを開いたブラウザーの `localStorage`（キー：`monosashi-v1`）に保存します。アカウント登録は不要で、回答や履歴をアプリからサーバーへ送る処理はありません。

記録は同じ端末・ブラウザー・オリジンでのみ利用でき、端末間では同期しません。ブラウザーのサイトデータ削除や保存制限で失われる場合があります。保存できないときは画面に通知します。学習履歴画面から結果・出題済み情報・復習リストをまとめて削除できます。中断中のクイズは残り、再開して表示した問題から新しく記録します。

チャレンジ回数と累計正答率は、**保存されている最新50回のうち、現行問題だけで受けたチャレンジ**を基準に算出します。累計正答率には同じ問題への再回答も含み、古い結果が保存対象から外れると変わります。

出会った問題数と直近の正誤は、結果履歴とは別の `learning` に保存します。クイズで実際に表示した時点で既出、回答を確定した時点で正誤を記録するため、未完了のクイズも反映されます。復習リストは現行IDの直近回答が誤答の問題です。復習で正解すると解除します。問題ライブラリ・結果画面の閲覧は出題済み記録に含めません。

旧形式の保存データは、有効な履歴と中断クイズの表示済み部分から移行します。すでに保存範囲から消えた過去の出題は復元できません。改訂前IDの学習状態を変更後の別IDへ移し替えず、同じ旧記録に含まれる現行IDの回答は個別に取り込みます。明示的に削除した空の記録を、中断クイズから自動で復活させません。

改訂前の問題を含む結果は「改訂前」と表示して残し、当時の問題・選択肢・正答で表示します。旧問題は新規出題、ライブラリ、復習から外します。選択肢改訂前に始めた12ジャンル版の中断データは、自由練習・復習・標準診断とも開始時の問題・選択肢で再開できます。標準診断1〜9は同じ版の過去結果との比較も維持します。最初の8ジャンル版を含む中断データは従来どおり終了し、画面に通知します。

## 静的ホスティング

`npm run build` で生成される `dist/` を静的ホスティングへ配置できます。Viteの `base` は `./` なので、サブディレクトリへの配置にも対応しています。開発サーバーやNode.jsを公開先で常駐させる必要はありません。CIには公開・デプロイ処理を含めていません。

Renderでは **Static Site** を選択します。ブランチは `codex/build-quiz-app`、Root Directoryは空欄、Build Commandは `npm ci --include=dev && npm run build`、Publish Directoryは `dist`、環境変数は `NODE_VERSION=24`。Start Commandは不要です。Renderが発行した公開URLは外部からアクセスできます。GitHubへのpush後に反映するには、自動デプロイを有効にするか手動デプロイを実行してください。
