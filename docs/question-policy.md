# 出題範囲と難易度の基準

このアプリは、主に日本で暮らす日本語利用者の身近な知識を対象とします。現行は2,889問で、知識2,669問と計算・読み取り220問を区別しています。診断は知識問題のみです。[今回の見直し](research/question-review.md)と[追加の経緯](research/overview.md)を参照してください。

## 知識診断と練習の区別（2026年9月7日）

知識診断（内部版 standard-v12）は、用語、仕組み、道具、制度、慣習などの事前知識を問います。知識を場面へ当てはめる問いも対象です。与えられた条件だけで解ける算術、時間や表の読み取り、架空ルールの適用は「計算・読み取り」とし、自由練習で選択します。安全な行動を問うというだけで知識問題とせず、設問以外に何を知る必要があるかを確認します。

各ジャンルは初級2・中級2・上級1問。お金・買い物は文章5問、残る10ジャンルは中級画像1問を含みます。対象ID・ジャンル・難易度・画像の有無を diagnostic-reviewed.json に固定し、出題範囲が変わる次回は版を更新します。

結果は正答率（四捨五入）と正解数を併記し、100点換算・ランクは表示しません。前回との差は正答率の差なので「ポイント」です。比較は同じ診断版に限ります。レーダーの未出題ジャンルは未測定です。

改稿は元IDに -r5 を付け、旧2,913問を depthEditionQuestions に保持します。退役した問いも questionMap に残し、昔の回答を新しい正解で採点し直しません。改稿・退役した旧IDの学習状態は現行の未出題判定に流用しません。

選択肢は同じ種類・詳しさでそろえます。正解だけを「場合がある」「条件を確認する」と広くし、誤答だけを断定する構成を避けます。問題文の単語を入れ替えただけで正解が作れる問い、無関係な誤答、成立しない仕組みを誤答にする問いは改稿または退役します。

## 採用する問題

- 日常の会話、文章、買い物、移動、家庭や仕事での基本的な判断に役立つもの。
- ニュースを理解するための基本的な地理、歴史、社会制度、経済の知識。
- 身近な自然現象や道具を、学校で習う基本的な知識で説明できるもの。
- 広く親しまれている文化やスポーツの基礎。

## 採用しない問題

- 法律の条番号や細則、業務用の会計・経済用語、ITの内部実装など、専門的な学習を前提にするもの。
- 化学反応の専門名称や詳細な成分、細かい分類、専門家向けの物理法則を暗記させるもの。
- 珍しい地名・人名・作品名・記録など、知名度の低い事実を当てる雑学。
- 主観的な慣習を、唯一の正しい常識として扱うもの。

専門用語を避けるだけでなく、設問が何を測っているかを確認します。専門的な内容を選択肢から容易に推測できても、一般常識の問題として採用しません。

## 難易度

| 難易度 | 基準                                                       |
| ------ | ---------------------------------------------------------- |
| 初級   | 身近な基礎知識を、そのまま答える                           |
| 中級   | よく見聞きする知識を区別し、意味や使い方を理解する         |
| 上級   | 基礎知識を組み合わせ、具体的な状況や文章・数字に当てはめる |

上級でも出題範囲は広げません。専門的・珍しい知識を増やすことで難易度を上げない方針です。選択肢は同じ種類のもっともらしい候補を用意し、極端に不自然な誤答だけで正解できる問題を避けます。

## 選択肢の作り方

- 誤答だけを「必ず・すべて・だけ・無条件」などの断定で見分けられる組合せにしない。数値条件や定義に必要な限定表現は残す。
- 同じ制度の別の項目、似た道具の用途、手順や判断の取り違えなど、知識を使って区別する候補を用意する。
- 四つの文型、長さ、具体性を近づける。正解だけが長く丁寧であったり、「確認する・相談する」と答えれば済む形になったりしないようにする。
- 断定語を取り除くだけで誤答を作らない。設問の条件と合わせて読み、別の選択肢も正しくならないか確認する。
- 一般的な基礎知識は初級のまま扱う。似た用語や用途の取り違えを問う場合も、曖昧な条件や専門知識の追加で難しくしない。
- 使い方・意味・違いが正答となる問題では、それを問題文で先に説明しない。知識を使って場面・操作・目的を選ぶ形にする。名称を答える基礎的な定義問題や、計算・安全・機種・施設の違いを一意にする条件は残す。
- ただし「個別条件を明示した」という理由だけで採用しない。「月曜が祝日なら翌平日休館。火曜が平日なら？」のように、初めて聞くルールをその場で当てはめるだけの問題は、知識を測る問題へ差し替える。ルールを長くしたり日付計算へ変えたりするだけでは改善としない。
- 設問を読んだ後に何の知識が必要かを具体的に挙げる。必要なのが記載内容の転記・比較だけなら見直す。お得比較など、日常の計算自体を目的とする題材はその目的で採用する。上級は身近な知識の組合せ・使い分けで判断させる。
- 図・代替説明・キャプションも同じ基準で確認する。図に描いた形や表示は説明するが、その意味や名称が正答なら説明文で先に明かさない。

価格比較では、単価・必要量を買う総額・今日の支払い・将来ポイントを使った実質額など、何を比べるかを明示します。税・送料・値引きの順序・ポイントの端数・有効期限・使い切れる量を必要に応じて指定し、架空の価格条件から正答と誤答を別計算で検証します。

## 修正時の記録の扱い

旧版の公開済み600問を `src/data/archive-v1.json` に内容を変えず保存しました。現行問題は `v2-` から始まる別IDを使用します。旧問題は新しいクイズ、問題ライブラリ、復習から外します。保存済みの結果は当時の8ジャンル・問題・正答で表示し、改訂前の結果であることを明示します。旧問題を含む中断データは終了して通知します。今後の改訂でも、公開済みIDに別の内容を上書きせず、版の判別・アーカイブ・保存検証を合わせて更新します。

選択肢の改訂では、元の2,239問を保持し、変更した問題に `-r2` を付けたIDを発行します。改訂前の12ジャンルの記録は12軸で表示し、最初の8ジャンル版と区別します。差し替えた旧問題は新規出題・ライブラリ・復習から外しますが、開始済みの12ジャンル版のチャレンジは開始時の選択肢で再開できます。この改訂差分も公開後は上書きせず、次の変更は別の版として扱います。

問題文の改訂では公開済み2,492問を保持し、変更した時点のIDに `-r3` を付けます。既存の `-r2` の内容も上書きしません。旧問題を含む履歴・中断データの設問・選択肢・採点を保持し、改訂後のIDは未出題として扱います。変更しなかった問題の学習状態は引き継ぎます。

さらに知識不要の条件読解を見直す改訂では、標準診断9時点の2,597問を保持し、その時点のIDに `-r4` を付けます。新規出題・ライブラリは改訂後を使い、過去の履歴と途中のクイズは開始時の内容で復元します。

今回の追加前の2,597問は `knowledgeEditionQuestions` に保持し、本文・選択肢・正答・出典が一致することをSHA-256で検証します。追加問題は独立したIDで未出題として扱い、標準診断11の対象メタデータは `src/data/diagnostic-depth.json` に固定します。

## 確認

1. 上の出題範囲に合うかを確認する。
2. 正解が一つに定まり、条件や例外が不明確でないかを確認する。
3. 制度・ルールなど、変わる可能性がある事実や不確かな事実は一次資料で確認する。
4. 同じ事実を別の言い方で繰り返していないかを全ジャンルで確認する。
5. 件数、選択肢、採点、旧履歴の互換性のテストを実行する。

難易度とスコアは編集上の学習目安であり、統計的に標準化された一般常識検査ではありません。

## 画像問題と標準診断

画像は `public/quiz/` に置くSVGです。自作の模式図と、国土交通省の利用規約に基づき加工・配置して出典を示す施設の案内用図記号を使います。正確な記号・数値・位置関係を一次資料や設問の架空条件と照合し、画像に頼らず同じ情報を読み取れる説明文を付けます。画像を読み込めないときも説明文を表示します。画像形式は難易度を意味せず、全152問は、いずれも中級に分類しています。道路標識は公式資料と形・色・図柄・意味を照合し、補助標識などの条件が必要なら設問に明示します。

旧標準診断11は当時の2,913問から、12ジャンル各5問（文章初級2・文章中級1・画像中級1・文章上級1）を選びます。以前の標準診断1は1,284問、標準診断2は2,004問、標準診断3は2,124問、標準診断4は改訂前の2,239問、標準診断5は選択肢改訂後の2,239問、標準診断6・7は2,372問、標準診断8は問題文改訂前の2,492問、標準診断9は条件読解の見直し前の2,597問、標準診断10は見直し後・今回の追加前の2,597問に固定し、履歴も中断データも当時の選択肢で復元します。診断の回答画面では正誤・解説を示しません。同じ版だけで前回比較し、自由練習や復習、異なる版の診断を比較に使いません。将来、対象問題や配分を変える際も診断の版を更新し、旧版の復元・比較を明示的に扱います。

## 未出題を優先する選出

自由練習・知識診断と旧標準診断7〜11では、先にジャンル・難易度・画像の配分を決め、同じ枠の候補から未出題を優先します。未出題が十分な枠では、1回の問数の20%を切り捨てた数までを任意の誤答再出題枠とし、枠の位置は毎回ランダムに決めます。直近回答が誤答の候補がない枠は未出題に使い、古い誤答から選びます。

ある枠の未出題が不足した場合は、誤答、最後の表示が古い出題済み問題の順で補います。この不足分は2割の上限とは別です。全問指定でも問数を減らさず、1回のクイズ内では重複させません。手動の復習は指定した誤答の全問を出題し、未出題を混ぜません。標準診断1〜6の抽選は学習状態に依存しない従来方式を保ちます。

実際に表示した問題と確定した回答をブラウザーに記録します。未表示の予約済み問題は記録せず、同じセッションの再開でも重複記録しません。結果履歴50件から独立して保持し、削除・移行・旧IDの扱いはREADMEに記載しています。

実装の確認では、未出題が十分ある場合の再出題上限、正答済み問題の除外、不足時の補充、全問出題を検証します。旧診断1〜11の対象・抽選・採点を保ったまま、知識診断の固定配分・計算問題の除外・改稿ID・退役IDの扱いを確認します。全画像の読み込み、追加題材の検索・絞り込み、スマートフォンでの回答後リロード復元、改訂前の設問と選択肢による再開・採点も確認します。最新の検証結果は[調査記録](research/overview.md)に記載します。
