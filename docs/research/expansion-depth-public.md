# お得比較と道路案内の追加

確認日：2026年9月7日。

既存の「どちらがお得？」に18問、「道路標識の見分け方」に画像10問を追加し、道路案内と移動に4問を加える。計32問（初級10・中級18・上級4）。既存の公開済み設問は変更しない。

## 比較問題の範囲

幅を含めた面積単価、増量と値引きの違い、内容量減少による単価上昇、家族券と追加人数、3個ごとの無料特典、最安商品が無料になる場合、回数券と単券の組合せ、通信量の追加購入単位、通話ごとの無料時間、暦日と24時間単位のレンタル、機械の容量と必要回数、商品券の機会費用、下取りと別途売却、ポイントの円換算、購入額と使用中の電気代、特典倍率の基準、値下げ後の値上げ、団体券と一人当たりの精算を扱う。

数字を変えるだけの単純な単価問題は増やさず、比較に必要な単位や支払い方法の違いを加えた。商品券は後日全額使用可能、売却価格は確定、電気代は一定の使用条件とするなど、主観や予想で正答が変わらない条件を指定した。金額・契約はすべて架空で、実際の店の料金や商品のおすすめを示すものではない。出典は比較の考え方の資料であり、架空の数値の出典ではない。

- [東京都消費生活総合センター・買い物比較表](https://www.shouhiseikatu.metro.tokyo.lg.jp/center/kyoiku/web/chu03/documents/comparison.pdf)
- [環境省・省エネ製品買換ナビゲーション](https://ondankataisaku.env.go.jp/shinkyusan/)

## 標識と道路案内

横風、路面凹凸、二方向交通、その他の危険、最低速度、ロータリー、右方屈曲、下り勾配、重量制限、最大幅を扱う。交通の方向や矢印、数字の単位を含め、自作のSVGと説明文を一致させた。二方向交通は左矢印が上向き、右矢印が下向きであることを公式図と照合。模式図の説明に標識の名称や意味は書かない。
