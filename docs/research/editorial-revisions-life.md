# 生活系4カテゴリの設問監査

確認日：2026-09-07。`artifacts/before-editorial.json` を基準に、家事302問、食と健康247問、防災162問、科学・世界197問、計908問の設問と正解を通読。候補の四択・解説・出典も確認し、30問を改訂した。

改訂数は家事19問、食と健康6問、防災2問、科学・世界3問。差分は `src/data/editorial-revisions-life.json`。現行IDをキーにし、元のデータ、カテゴリ、難易度、画像ファイルは変更していない。アクティブな改訂IDと過去記録の扱いは統合側で行う。

## 主な修正

| 対象             | 変更前の問題点                                 | 変更後                                                     |
| ---------------- | ---------------------------------------------- | ---------------------------------------------------------- |
| 送風・解凍       | 問題文中の機能説明が選択肢と同じ               | 機能名から働きを判断、または具体的な調理場面から機能を選択 |
| 食洗機の乾燥     | 「乾燥のみ」で乾かしたいので同名機能を選ぶ     | 機能を使える食器の状態を選択                               |
| 掃除機の弱運転   | カーテンに吸い付く際の答えを説明書引用で先出し | 生地が吸い付く場面から調整する設定を判断                   |
| 再熱除湿         | 二方式の定義を先に全文掲載                     | 部屋の状況から、機能の違いを知って選ぶ                     |
| ベッドの重ね順   | 正解の並びが問題文にそのまま書かれている       | 個別製品の名前を挙げ、一般的な順序を問う                   |
| 洗濯機の予約画像 | 8時間後に終わると書いて、同じ説明を選ぶ        | 21時に設定したときの終了予定時刻を計算                     |
| 防虫剤           | 「衣類の上に置く」と指定した上で置き場所を聞く | 出典製品の置き場所を、収納内の候補から選ぶ                 |
| 漂白剤           | 酸素系を使えると提示した上で酸素系を選ぶ       | 液体という形状で系統を決められるか判断                     |
| 冷凍食品         | 「凍ったまま」の指示の言い換えを選ぶ           | 解凍の要否を調べる表示を、紛らわしい表示から区別           |
| 米袋             | 「精米時期は精米した時期」という同語反復       | 産年と精米時期の組合せを読み分ける                         |
| 灯油             | 灯油指定と書いてから燃料を問う                 | 家庭用石油ストーブの燃料を識別                             |
| 吸音・遮音       | 両方の働きを問題文で説明していた               | 用語に対応する働きの組合せを選ぶ                           |
| 透水性舗装       | 雨をしみ込ませると書いて、地中へ戻す答えを選ぶ | 名称から雨水の行き先を判断                                 |
| 月間降水量       | 同じ100mmと書いて同じ合計を選ぶ                | 異なる降り方の二都市で、月の合計と1日最大量を比較          |

正解だけが詳しい・慎重な説明にならないよう、位置・操作・機序など比較する軸をそろえた。食用の冷凍品の誤答も、産地や購入日の天候のような遠い候補から、内容量・凍結前加熱・原材料表示へ変更した。

## 維持した条件

- 予約時間が開始と終了のどちらを指すかは機種で異なる。画像中の定義を残し、時刻計算に変更した。
- 再熱除湿はその機能を備えた機器に限定する。存在しない機能を一般の機器へ適用しない。
- 炊飯器の再加熱対象はメーカーの案内に限定。冷凍・冷蔵ご飯に使えると一般化しない。
- 衣類の手入れでは素材・取扱表示への適合、衛生や事故対応では必要な状況を維持する。
- 初級の「定義から名称を選ぶ」問題は、それ自体を不備とは扱わない。計算に必要な数値、規約の違いを決める条件、危険を判断する前提も単に難しくするためには除かない。
