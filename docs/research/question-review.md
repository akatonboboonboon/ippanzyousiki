# 利用者の指摘を踏まえた診断・問題・画面の見直し

## 指摘と対応

| 指摘 | 対応 |
| --- | --- |
| 知識と推論が混ざり、測るものが不明 | 知識診断を新しい版として分離。計算・読み取りは自由練習で選択 |
| 60問なのに85/100と表示される | 正答率85%と60問中51問正解を併記。履歴と前回比較も単位を修正 |
| UIが装飾的 | ホームの見本チャート、傾いたカード、飾りの星、重複した説明を除去。結果のランクを廃止 |
| 問題が答えの言い換え | 設問以外の知識が要るかを点検し、改稿・練習へ分離・退役 |
| 誤答だけ断定的で正解が広い | 同じ種類の候補・同じ詳しさへ改稿。無関係な誤答も交換 |
