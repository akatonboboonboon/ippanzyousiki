## 重複・品質確認

- `artifacts/current-2124-bank.json` の既存問題文と正答を検索。充電池の回収、膨張、誤飲、短絡、リデュース等は追加しない。
- 皮膚に付いた薬品を流水で洗う問題は、既存 `v2-safety-expanded-easy-008` と初動が同じため不採用。白い粉の認識と接触予防へ変更した。
- 特定 CD ラジオの電源切替仕様は一般性が低いため不採用。白い粉の認識と、機器内部への液の侵入を相談する判断は別の論点として扱う。
- 家電の料金 2 問は、基本の費目と、自分で指定引取場所へ運ぶ場合の費目の違いを問う。既存の単純な言い換えはない。
- ID・問題文の既存との完全重複なし。35 ID は一意で、各問の選択肢 4 件も一意。全問に説明・topic・source を付与。
- 対象ファイル単独の TypeScript 型検査成功。採用出典 18 URL は HTTP 200 を確認。
