# お金・契約・行政手続・仕事：一般常識の範囲を広げるための調査

調査日：2026-09-06。調査担当範囲のみ。問題バンクは変更していない。

## 調査から分かった対象範囲

「一般常識」の統一された公的な全領域リストは、今回の資料では確認できない。一方、金融庁は家計管理・生活設計・金融取引・外部の助言利用を生活スキルとして整理し、消費者庁は社会人向けにも契約、勧誘、被害救済を扱う教材を公開している。[S01][S05]

したがって、学校の教科名だけを分類の軸にするより、**生活で遭遇する場面と、そこで読み取る情報・利用する制度**を軸にした方が、このアプリの目的に合う。これは資料を踏まえた編集上の提案であり、「これを知らない人は非常識」という公的判定ではない。

| 領域                     | 含める知識・判断                                                 | 混ぜないもの                                                     |
| ------------------------ | ---------------------------------------------------------------- | ---------------------------------------------------------------- |
| 家計・支払い・借入れ     | 明細、手取り、支出予定、後払い、手数料、返済総額                 | 推奨投資商品、資産額による人物評価、金融資格用の計算             |
| 買い物・契約・消費者対応 | 合意、契約記録、返品・解約、定期購入、住まいの契約、相談先       | 例外を隠した法律の断言、条文番号・罰則額の暗記                   |
| 税・社会保険の入口       | 年末調整、確定申告、住民税、年金の役割、免除・猶予、退職時の確認 | 毎年変わる控除額・所得境界・保険料の丸暗記                       |
| 行政手続・公共サービス   | 住民票と戸籍、転出入、代理請求、郵便転送、困りごとの窓口         | 特定自治体の窓口階数・料金・独自期限を全国共通扱いすること       |
| 働くときの権利と確認     | 労働条件、勤怠、給与、休暇、労災、求人・雇用保険、相談           | 無償残業・同調・上下関係への服従を「常識」とする出題             |
| 仕事・共同作業の情報共有 | 指示の確認、数量・期限・担当、引継ぎ、事実と推測、意思疎通       | お辞儀の角度、飲み会参加、電話を何コール以内に取るか等の一律採点 |

資料が学校用かどうかと、題材が学校の暗記知識かどうかは別。給与明細・契約確認などは学校用資料でも裏付けに使える。ただし、対象者や典型的な家族像を全利用者へ押し付けない。

## 候補の読み方

以下は **80件の題材候補**。完成した四択問題や採用決定ではない。

- **基礎**：仕組み・用語・窓口の意味を問う。
- **場面**：短い明細、契約画面、連絡文等を提示して判断する。数値や状況は新規作成する。
- **条件**：対象者・時点・契約・地域を明示し、実装時に現行資料で再確認する。
- 出典は、その題材を扱う根拠。とくに情報共有の「場面」は、資料の考え方から作問者が構成する推論であり、資料にそのまま掲載された模範解答ではない。

## 採用前に決めたい基準

1. **生活上の基本事項の確認**と**具体的場面の読み取り**を中心にする。「日常題材に法律の難問を移しただけ」にならないよう、数字・例外・条文が正解の中心なら優先度を下げる。
2. 出典付きでも常に一意に答えられるとは限らない。契約・勤務形態・自治体・年を隠さない。答えが変わる候補は条件を示すか見送る。
3. 易しい問題は用語・役割、標準は1つの場面、難しい問題は複数の条件を比較する形式にする。専門用語や例外の追加を難易度上昇に使わない。
4. 正解だけが立派で、誤答が「無視する」「全部捨てる」「必ず従う」になる問題は作り直す。明細欄・似た手続・対象期間・条件の読み違いを誤答にする。
5. 「手取りと額面」「アプリ削除と解約」「転入予約と転入届」など、似ているが異なる概念を優先する。相談先の番号だけで水増ししない。
6. 専業主婦・主夫、学生、無職、自営業、外国籍、単身、育児・介護中などの利用者にも分かる文面にする。就業・結婚・持家・投資を人生の必須条件にしない。
7. 働くときの権利は、権利の存在と確認先を学べるようにする。実行できなかった人や被害者の人格・常識度を否定する採点にしない。
8. 問題には分野に加えて、場面タグ、根拠URL、確認日、適用条件、見直し要否を持たせることを提案する。最終スキーマは本調査の担当外。
