# 一般常識クイズの範囲を調べ、生活中心の問題集へ再構成

調査・編集基準日：2026年9月6日。対象は主に日本で暮らす日本語利用者です。

## 調査から分かったこと

「一般常識」には唯一の完全な一覧があるわけではありません。実際のクイズ集も、教科・就職試験、生活慣習、社会人の連絡、身近な雑学など、対象が異なります。今回の調査では既存サイトを題材の抜けの発見に使い、正答の確認には公的機関・事業者・実務資料を使いました。設問や選択肢のセットは転載していません。

これらは出題範囲を設計するための調査であり、公的機関が本アプリの「一般常識度」を認定したという意味ではありません。独自の場面問題に付けた出典は、その場面に適用した原則の参照先です。場面中の架空の時刻・金額・案内文が出典にそのまま掲載されているわけではありません。

## 品質と継続的な見直し

地域のごみ分別、葬儀の宗派、施設の利用条件、製品ごとの扱いは、全国共通の一つの作法として断定しません。制度・交通・健康・安全の問題には条件を付けて根拠を確認し、細かな罰金額、保険料率、最新の人物名など更新の速い数値暗記は抑えています。

上級を専門用語の暗記にしません。例として、開封済み食品に未開封の期限を当てはめないこと、遅延証明書で証明される範囲、定期購入の解約条件の読み合わせなどを使います。同じ事実の単なる言い換えや、正解が複数になり得る設問を避けます。難易度は編集上の目安です。

旧版の600問は当時の結果を正しく表示するためのアーカイブにのみ残しています。新しい問題には別IDを付け、昔の回答を新しい正解で採点し直しません。実装の確認項目と運用上の編集基準は[出題方針](../question-policy.md)に記載しています。

標準診断1は12ジャンル各5問、合計60問。各ジャンルで文章初級2・文章中級1・画像中級1・文章上級1の配分です。将来の追加で母集団が変わらないよう、今回の1,284問のID範囲を固定しました。正誤と解説は終了後に提示し、同じ版の結果だけを比較します。自由練習は従来どおり問数・ジャンル・難易度を選べます。
